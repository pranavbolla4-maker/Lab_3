# Tip Calculator

## Description
A C++ console program that allows users to quickly calculate an accurate tip amount and the final total bill based on a custom bill amount and tip percentage.

## How to Run
1. Open the project folder in Visual Studio.
2. Press Ctrl+F5 to build and run.
3. Enter the bill amount and tip percentage when prompted (bill must be greater than 0).

## Sample Input / Output
Input:  Bill Amount: $50.00, Tip Percentage: 15%
Output: Tip Amount: $7.50, Total Bill: $57.50
